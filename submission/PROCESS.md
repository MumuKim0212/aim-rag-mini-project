  - 15개 약관 모두 출처 목록과 본문 조 순서가 일치한다
  - 용어집 "공매도"는 두 번(dicId 1859, 1865) 같은 정의로 실려 있다(POS026, POS043)
- 근거 구절: 답변 가능 148문항 전부 사람이 원문 줄 단위로 골랐다. 353구절이 대상 페이지와 자동 대조로 모두 일치한다(공백 제거·NFKC). 정답 페이지는 모두 해당 범위의 인덱스 대상이다
- VLM 보충 근거: 표·차트 19문항은 VLM이 정리한 표 행·차트 수치를 근거에 더했다(`evidence_source: text+vlm`). 텍스트 레이어에서는 항목명과 값이 다른 줄로 흩어져 있어서다. 쓴 15쪽을 PDF 페이지 이미지와 대조해 모두 일치했다
- 정답 페이지 추가: POS019·NEG019는 같은 규정이 02약관 제2조③(p.1)에도 있어 그 페이지도 정답으로 넣었다
- 정답 페이지에서 뺀 것: 조문이 다음 쪽으로 넘어가지만 답과 무관한 꼬리 4문항(POS027, POS047, POS049, POS060)
- 고친 기준 답안·질문: 0건. 원문 자체의 불일치 1건(ADD-RP06: 퇴직연금 요약 p.1의 16.8% vs 본문 p.3의 16.1%)은 기록만 했다
- 테스트: `tests/test_provided_golden.py`(문항 수·분할·근거 대조)

#### 2.3 알려진 약점
_맥락 전제 질문, 중복 내용 문서, 쉬운 문항 비율 등_

- 맥락 전제 질문 34문항("이 자료", "책에서", "가이드북", "그래프" 등, dev 20 / test 14). 금융생활 17, 추가 16, 기본 1. 제공 질문이라 고치지 않았다. 범위 B에서 "가이드북"은 금융생활 가이드와 보험약관 이용 가이드북 둘을 가리킬 수 있다
- 표 숫자만 있는 짧은 줄은 근거 대조(`evid`)에서 빠진다. VLM 표 행이 이를 보완하지만, 텍스트 레이어만 담긴 청크에서는 표 행이 대조되지 않는다
- POS079: 학자금대출 비교표가 p.30–31에 걸치고 셀 단위로 흩어진다. VLM 보충이 이 표를 정리하지 않아 텍스트 레이어 조각만 근거다
- 답변 불가 32문항은 정답 페이지가 없어 검색 지표에서 빠지고 상태 판정으로만 평가된다
- 기본 positive는 용어 정의형이 많고(용어집만 근거인 문항 27), 근거가 정의 한두 줄이라 쉬운 문항 비율이 높다
