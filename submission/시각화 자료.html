실제로 지나간 길 (연습 문제 POS061)

질문: "첫 월급을 받았는데 목표가 그냥 '돈 많이 모으기'예요. 가이드북에서는 이런 목표를 어떻게 바꾸라고 하나요?" 정답이 있는 쪽(20대 금융생활 가이드북 p.10)의 조각은 검색 점수로 6번째·10번째였습니다. 점수 순으로 5개만 넘겼다면 근거를 놓쳤을 질문인데, AI가 15개를 읽고 6번·10번을 골라 정답을 썼습니다. 최종 시스템은 모든 질문이 이 3칸을 한 번씩 지나갑니다(AI 호출 2번, 5.7초). 초록 = 지나간 칸, 번호 = 지나간 순서.

Agent v2해 봤지만 효과가 없던 것

Agent v2 (시험 뒤 추가 실험, 버림): T3에 "답 검사" 칸을 더했습니다. 다른 AI가 답 초안에서 빠진 내용을 찾고, 있으면 1번 고쳐 쓰게 했습니다. 질문 종류 판단 결과도 답 쓰는 칸에 넘겼습니다.

결과: 연습 문제 0.928로 T2와 같았습니다. 검사 칸이 90개 중 3개만 지적했고, 겨냥한 "한 가지를 빠뜨린 답" 10개는 하나도 잡지 못했습니다. 비용만 1.5배라서 쓰지 않았습니다.

그 밖에 효과가 없던 것결과
조각 크기만 바꾸기 (400~1,200자)모두 운의 범위 안. 크기보다 어디서 자르느냐(용어·조항 단위)가 중요했습니다
단어 검색(BM25)만 쓰기용어 질문에서도 근거를 찾는 비율이 오히려 낮았습니다 (0.80 대 뜻 검색 0.96)
찾는 개수 3개 / 8개3개는 근거를 놓치고, 8개는 글이 너무 길어져 5개를 유지했습니다

배운 점

  • 점수를 올린 건 "찾는 방법"을 고친 일이었습니다. 용어·조항 단위로 자르기(정답 쪽을 찾는 비율 0.88 → 0.96), AI가 다시 고르기(0.883 → 0.928).
  • Agent는 남은 실패에 맞춰 설계해야 합니다. 검색을 먼저 다 고친 뒤에는 Agent가 겨냥한 "못 찾음" 실패가 거의 사라져 있었습니다.
  • 작은 차이는 운일 수 있습니다. 같은 설정도 다시 돌리면 90문항 중 14문항이 바뀌어, 그보다 작은 차이는 개선이라고 하지 않았습니다.
